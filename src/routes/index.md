## Welcome to Gulp DevStack

This is a modern frontend development environment with Gulp, Bootstrap, and Nunjucks templates. Use it to create static websites or prototypes with ease.

### Getting Started

1. Clone the repository
2. Run `npm install`
3. Start development with `npm run dev`
